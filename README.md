# Learning Pi (`learn_pi`)

A playground and repository for exploring [pi](https://github.com/earendil-works/pi-coding-agent) coding agent capabilities, custom extensions, skills, and Nix development environments.

## Features

- **Nix Flake**: Provides a reproducible development environment with Node.js, Bun, and Nix formatting.
- **Custom Skills**: Includes custom skills such as `git-release` for automated GitHub releases and changelog generation.

## Development

Enter the Nix development shell:
```bash
nix develop
```

## Releases

Releases are managed via the `git-release` skill and GitHub CLI (`gh`).
